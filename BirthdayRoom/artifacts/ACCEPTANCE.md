## 性能观测

这些是本次运行的局部观测，不是所有设备的帧率保证。

| 环境及阶段 | 观测 |
| --- | --- |
| 本机内置浏览器，房间总览 | 一次 2 秒滚动窗口读取约 120 FPS、524 draw calls |
| 本机 WebKit，iPhone 视口，最终首屏 | Apple GPU，约 56 FPS、524 draw calls |
| 完整流程的移动 WebKit，结尾阶段 | 约 60 FPS、229 draw calls |
| Chromium headless，最终首屏 | 确认为 SwiftShader 软件渲染，约 6 FPS；完整流程期间 3–8 FPS，不能代表真实桌面 GPU 或实体手机的速度 |

地板、植物使用实例化，静态阴影缓存，移动设备限制像素比与阴影成本；自动画质在持续低帧率时会降级。生产 JavaScript 共约 1.36 MB，gzip 合计约 392 KB。Vite 对 Three.js 核心约 704 KB 的单块给出体积提醒；它不影响构建成功，日志原样保留。

## 已知边界

本项目依据附件里的文字进行原创设计，没有收到参考视频，未声称逐帧复刻。未使用外部模型、商业音乐或云端音频 API。麦克风吹蜡烛为可选项，本版本没有实现麦克风输入，以通用按钮完成所有流程。不请求额外设备权限。

个人信息均可在 `src/config/birthday.ts` 配置；当前是「亲爱的你」的可运行默认版本。游戏存档仅在当前浏览器的本机存储中保存；中途刷新最后的演出会恢复到已完成贺卡，并允许重播。

最后的修改包括手机首屏构图、安全区、桌面小物与展开面板的空间避让，以及密码输入框聚焦时的 Esc 行为。生产构建、最终 3 项回归和新截图在这些修改之后执行；三个浏览器的完整故事通关记录保留在独立的完整报告中。
