# Toolbox migration

On 2026-10-28, Birthday Room was moved into the public `hhhoratioxu/Toolbox` repository under `BirthdayRoom/`, from source commit `f232158852c395ce1f39e70ed173911d8cec812c`.

The application source, puzzles, tests, lockfile, license and real screenshots are retained. The repository metadata, clone instructions and Pages base path are updated for the new location. The active workflow lives at the Toolbox repository root, `.github/workflows/pages.yml`; there is no nested inactive workflow in this tool directory.

Public experience: https://hhhoratioxu.github.io/Toolbox/BirthdayRoom/

The original browser acceptance artifacts remain historical evidence of the original application. A migration deployment must be checked separately through the Toolbox Pages workflow and the live URL.
