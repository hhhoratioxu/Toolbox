# Public source publication

The public source is exported from the verified Birthday Room implementation. The src/ and tests/ files are byte-identical to the tested local project. Only repository metadata, documentation, redacted diagnostic paths and lossless screenshot formats were prepared for publication.

Before publication, TypeScript, the production build and all 29 Vitest checks passed again in the public checkout on 2026-10-19. The prior browser acceptance records are retained as historical local evidence; they are not GitHub Actions results.

Private hosting identifiers, local dependencies, generated output, environment files and private Git history are excluded from the public repository.
