# Real application screenshots

These images were captured from the running Birthday Room WebGL application during local acceptance testing. They are lossless WebP conversions of the original PNG screenshots. Decoded RGBA pixels were compared byte for byte before publication.

- `room-desktop.webp`: desktop welcome screen
- `room-mobile.webp`: mobile welcome screen
- `cake.webp`: the birthday cake and candle sequence
- `greeting.webp`: the final birthday card
