HoriPet 0.1.0 Preview — 一点点，温柔的陪伴。

An original, offline desktop cat for macOS and Windows. Includes three coats, ten animation states, dragging, nearby cursor following, local care statistics, bilingual preferences, native tray recovery and multi-display bounds handling.

**Unsigned preview / 未签名预览版**

- macOS ARM64 and Intel: DMG installer and ZIP.
- Windows x64 and ARM64: per-user NSIS installer and Portable executable.
- No Apple Developer ID/notarization or Windows trusted code signature is claimed. Internet downloads may trigger Gatekeeper / SmartScreen. Verify the repository and SHA256 before using the system-provided open flow; do not disable system protection.
- Windows ARM64 is cross-built. Installer generation is distinct from hardware acceptance.
- Packaged-app automation reports and screenshots are available in the matching Actions run. See `docs/VALIDATION.md` for the precise verification boundary.
- Core features make no network requests. No account, API key or subscription required.

Mac: drag HoriPet into Applications before enabling login startup. Windows: use Setup for login startup; Portable does not register it.

Click to pet, double-click for affection, drag to move, right-click for actions. The menu bar/system tray always provides Show, Preferences, Restore position and Quit. Closing preferences keeps the companion running.
