# 已实现、未实现与限制

## 已实现

- 单用户持久化账户、Argon2、HttpOnly Cookie、登录节流、Origin/Host 检查。
- 独立 Agent PAT、后端项目/分类/敏感级别/外部许可权限、撤销、最近访问。
- 项目管理，六种事实性记忆分类与独立 AI 人格、标签和项目分开建模。
- 创建、修改、确认、拒绝、锁定、置顶、归档、回收站、恢复、来源闭包彻底遗忘。
- 原文、逐字引用与位置、完整版本、元数据/正文差异、新版本恢复。
- 三种写入模式，默认候选审核；项目范围内的受限自动保存。
- TXT/Markdown/JSON 导入、原文预览与片段读取、内容去重、重试幂等。
- 中文关键词匹配、可选 pgvector 语义检索、当前版本索引失效和正文降级。
- 按身份→人格→资料→项目→问题检索构建上下文，预算与裁剪说明、来源和版本清单。
- 持久任务与后台提炼、引用校验、失败原因、重试、检查点先保存。
- 关键词/同标题的保守重复与冲突发现，纠错/时间变化/合并，保留历史。
- HTTP API、官方 MCP Streamable HTTP、两个可运行适配器与客户端触发规则。
- 九个中文管理区域、手机布局、深浅色主题、真实后端按钮与错误提示。
- 完整逻辑备份、恢复、删除日志重放、恢复后撤销凭证、重建索引。
- Docker Compose、锁定镜像、Caddy HTTPS 配置、迁移、OpenAPI 和中文操作文档。

## 明确未实现

- OAuth 授权服务器、OAuth discovery / DCR / PKCE 接入；仅支持独立 Bearer PAT 的客户端。
- 任何商业封闭客户端的自动历史获取、自动注入或真实兼容性认证。
- OpenAI 等云端私有模型 API 的专用鉴权适配器；目前是可替换的 Ollama 兼容适配层。
- 原生多用户、多租户组织、知识图谱、复杂统计、原生手机 App、完整离线同步。
- 自动定时创建/异地上传/加密备份；提供真实备份恢复和保留策略，调度与加密由部署者配置。
- 对任意语义改写副本的全局“遗忘识别”、外部服务或旧会话的远程撤回。
- 通用模型 tokenizer；使用明确标示的保守估算。
- HNSW 近似向量索引、大语料压测和语义重排模型；当前是 pgvector 精确向量查询。
- 对所有模型自动提炼正确性的保证；引用真实存在不能单独证明模型理解正确，默认仍需审核。

## 重要实现限制

- 冲突发现使用同标题/高文本相似度启发式，不是完备的事实冲突推理。存在冲突时上下文会排除相关结构化记忆及关联原文，等待用户审核。
- 项目“记忆与时间线”复用按修改时间排列的项目记忆列表，不是独立的可视化甘特/事件图。
- 来源是单项目、单分类的权限单元；混合敏感资料应拆分导入。原文权限不会随记忆降低；已有记忆不能直接降低敏感级别或扩大外部许可，需要创建独立、经脱敏且授权的来源。
- 管理员记忆详情可看历史；Agent 只获得有效版本及当前引用。旧来源因纠错被停止提炼后，仍保留给用户审阅历史。
- 彻底遗忘会处理整个已知来源依赖闭包，可能连带删除共享来源的多条记忆；必须先查看影响范围。本版提供整份删除/整份脱敏，尚无局部精细脱敏编辑器。
- 同原文重传和同键重试可避免重复；多轮语义近似改写仍可能成为不同候选，需审核合并。
- 修改原文保留策略只影响新来源的期限；来源到期时结构化记忆仍保存最小引用，彻底删除请用遗忘。
- 服务端只知道检索、返回及客户端回执，不知道模型内部是否采用。
- 界面文件导入 2 MB、HTTP 请求体 8 MB；大备份走 CLI。单次关键词候选最多 1,000 条，个人规模以外需要升级检索策略。
- 管理员会话默认 12 小时。当前没有密码重置网页或 MFA；初始化幂等，不会覆盖已存在的管理员。服务器账户管理需由管理员维护。

## 未在当前环境实际验证

公网域名与证书签发、Docker 容器构建与编排启动、真实 Ollama 成功推理和真实 Embedding 语义质量、两台物理电脑访问、第三方商业客户端 UI 接入。已经验证的是同一服务上的两个独立客户端凭证与协议、真实浏览器管理操作、真实 PostgreSQL/pgvector、重启和备份恢复。
